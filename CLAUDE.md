# Universal Claude instructions

## Style
- Be concise. Lead with the answer; skip preamble and recaps.

## Coding
- Always test your changes before calling them done.
- When possible, write unit tests for new or changed code.
- Report test failures honestly, with the output.

## Tools (MCP)
- Use MCP tools when available for:
  - UEFN (Unreal Editor for Fortnite)
  - Roblox Studio
  - ArtCraft
